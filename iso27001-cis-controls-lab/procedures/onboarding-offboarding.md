# Onboarding and Offboarding Procedure

## Onboarding
1. HR submits approved onboarding request
2. User accounts created based on role
3. MFA enabled before access granted
4. Security awareness training assigned
5. Access approvals documented

## Offboarding
1. HR notifies IT immediately upon termination
2. Disable accounts within required timeframe
3. Revoke VPN, email, and privileged access
4. Recover company assets
5. Archive user data where required
6. Document completion of offboarding tasks

## Compliance
- ISO 27001 A.5.15 Access Control
- CIS 5 Account Management
