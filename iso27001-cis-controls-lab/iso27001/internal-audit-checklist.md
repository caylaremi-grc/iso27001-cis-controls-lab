# Internal Audit Checklist

## Governance
- [ ] Information Security Policy approved
- [ ] Risk assessments performed annually
- [ ] Statement of Applicability maintained
- [ ] Vendor reviews completed

## Access Control
- [ ] MFA enabled for critical systems
- [ ] Access reviews completed quarterly
- [ ] Privileged accounts monitored

## Asset Management
- [ ] Asset inventory maintained
- [ ] Data classification applied

## Logging & Monitoring
- [ ] SIEM alerts configured
- [ ] Logs retained per policy
- [ ] Incident escalation documented

## Backup & Recovery
- [ ] Backups encrypted
- [ ] Recovery tests performed
- [ ] Immutable backups configured

## Incident Response
- [ ] Incident response plan tested
- [ ] Security incidents documented
- [ ] Lessons learned recorded
