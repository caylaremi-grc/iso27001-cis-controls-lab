# ISO 27001 + CIS Controls Security Program Lab

## Project Overview
This repository simulates the implementation of an Information Security Management System (ISMS) aligned with:
- ISO/IEC 27001
- CIS Controls v8

The objective of this project is to demonstrate practical Governance, Risk, and Compliance (GRC) skills through:
- Risk assessment
- Control implementation
- Security governance documentation
- Internal audit preparation
- CIS Controls mapping

---

## Company Scenario
| Field | Value |
|---|---|
| Company Name | Leman Health Service |
| Industry | Healthcare |
| Employees | 120 |
| Locations | 2 Offices |
| Infrastructure | Microsoft 365, Windows endpoints, cloud-hosted webb app |
| Sensitive Data | Patient records, HR data, financial data |
| Compliance Drivers | ISO 27001, GDPR |

## Project Objectives
- Establish a basic ISMS
- Identify and assess risks
- Map controls to ISO 27001 and CIS Controls
- Create governance documentation
- Simulate audit preparation activities
