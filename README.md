# ISO 27001 & CIS Controls Security Program Lab

## Project Overview

This repository simulates the implementation of an Information Security Management System (ISMS) for a healthcare organization aligned with:

- ISO/IEC 27001:2022
- CIS Controls v8

The project demonstrates practical Governance, Risk, and Compliance (GRC) and security operations concepts through:

- Risk assessment and treatment
- Security governance documentation
- Control mapping and implementation
- Vendor risk management
- Internal audit preparation
- Incident response and operational procedures

---

## Simulated Company Environment

| Field | Value |
|---|---|

| Sensitive Data | Patient records, HR data, financial information |
| Compliance Drivers | ISO 27001, GDPR, Swiss FADP |

---

## Project Objectives

- Establish a foundational ISMS program
- Identify and assess organizational risks
- Map controls to ISO 27001 Annex A and CIS Controls v8
- Develop governance and operational security documentation
- Simulate internal audit and compliance activities
- Demonstrate risk-based security decision-making

## Frameworks & Standards Used
